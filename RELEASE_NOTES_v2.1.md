# NowPianoV2 v2.1

## Новые возможности

- Запись исполнения с внешней MIDI-клавиатуры.
- Отображение записываемых нот на нотном стане в реальном времени.
- Управление записью: Старт, Пауза, Продолжить и Стоп.
- Экспорт записанного исполнения в MIDI.
- Экспорт нотной партитуры в PDF через MuseScore 4.

## Поддержка MIDI

- Добавлены Mido и RtMidi.
- В сборку включён нативный модуль RtMidi.

## Комплектация

All-in-One установщик включает FluidSynth, SoundFont, Audiveris, HOMR и Poppler.

## Требования

- Windows 10/11 x64.
- Для экспорта партитуры в PDF требуется отдельно установленный MuseScore 4.
- Внешняя MIDI-клавиатура необязательна.

## Установка

Скачайте NowPianoV2_Setup_Final.exe из Assets этого релиза.
