# NowPianoV2 v2.1 — Full Offline Installer

Полная автономная сборка NowPianoV2 для Windows x64.

## Состав установщика

Файл: `NowPianoV2_Full_Setup_20261103.exe`

В комплект входят:

- NowPianoV2 — приложение Python/Qt;
- MuseScore Studio 4.7.5 для конвертации партитур в PDF;
- Audiveris с необходимой средой Java;
- HOMR;
- Poppler;
- FluidSynth и SoundFonts;
- инструменты распознавания, включая Tesseract.

Для конвертации партитур и экспорта в PDF отдельная установка MuseScore не требуется.

## Возможности v2.1

- Запись и воспроизведение MIDI-исполнения.
- Отображение нот на нотном стане во время игры.
- Режим обучения и контроль правильности нажатий.
- Работа с MIDI-устройствами.
- Импорт и экспорт MIDI.
- Экспорт нотных материалов в PDF через MuseScore Studio 4.
- Перетаскивание файлов в окно программы.
- Поддержка загрузки и воспроизведения MIDI/KAR.

## Установка

Скачайте `NowPianoV2_Full_Setup_20261103.exe`, запустите установщик и следуйте инструкциям.

Драйвер MIDI-устройства при необходимости устанавливаются отдельно.

Исходный код проекта доступен в этом GitHub-репозитории. Файлы сборки и инструкции находятся в каталоге `installer`.
