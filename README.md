  * **Теория музыки** — правила, тональности, тренажёр чтения нот с листа;

## 🇬🇧 Full Feature Overview (English)

**NowPiano 3.2** is a standalone desktop environment for piano education, sheet music practice, optical music recognition (OMR), and real-time accompaniment arranging. Everything is bundled in a single installer—no internet connection or Python setup required.

### Core Modules & Features:
* **🎓 Academy (Grades 1–10) & Solfeggio:** structured step-by-step piano curriculum and ear-training exercises.
* **🏫 Music School (4 Subjects):**
  * **Piano Performance** — graded repertoire across Grades 1–10;
  * **Solfeggio** — ear training, intervals, and chords;
  * **Music Theory** — fundamentals, key signatures, and sight-reading trainer;
  * **Music Literature, Exam Mode & Progress Journal** with hover tooltips.
* **🎼 Virtuoso Pianist (All 60 Hanon Exercises):** complete 60-lesson course (Parts I, II & III) in Sheet Music and Piano Roll views, live BPM tempo synchronization, expressive dynamics, and real-time finger numbers (`1–5`) rendered directly on the piano keys.
* **🎮 Interactive Piano Games (88 / 76 / 61-key adaptive):**
  * *Note Fall*, *Musical Echo*, *Note Sprint*, *Interval Hunter*;
  * *Chord Master* (6 levels + blindfold memory exam);
  * *Accompaniment & Jam* with live Piano Roll.
* **🪄 Smart Arranger (Auto-Bass & Rhythm):** records your melody onto the solo staff from the very first keystroke while preserving real timing, rests, note durations, and touch velocity; includes 8 accompaniment patterns and one-click bass/chord generation.
* **🎙 Studio Overdub & Export:** multi-layer recording over existing scores, clean **PDF** export (preserving solo/bass hand color coding), and **MIDI** export.
* **📷 Offline Sheet Music OCR & All-in-One Bundle:** includes **HOMR + RapidOCR + Audiveris + Java + Poppler**, **FluidSynth + SoundFont**, portable **MuseScore 4**, 3 UI themes (*iOS Light*, *Dark Studio*, *Classic*), and **Smart Auto-Updater**.

### 核心模块与特性：
* **🎓 钢琴学院（1–10级）与视唱练耳：** 从基础手型到高阶曲目的系统化分阶段钢琴课程与听力训练。
* **🏫 音乐学校（四大科目）：**
  * **钢琴演奏** — 覆盖 1–10 级的分级练习曲与乐曲；
  * **视唱练耳** — 听觉训练、音程与和弦辨识；
  * **基本乐理** — 乐理知识、调号与五线谱视奏训练器；
  * **音乐文学、考级测评与学习成绩单**（支持鼠标悬停提示）。

* **📷 离线识谱引擎与全能内置组件：** 内置 **HOMR + RapidOCR + Audiveris + Java + Poppler** 离线识谱引擎、**FluidSynth + SoundFont** 高品质钢琴音源、便携版 **MuseScore 4**、三套界面主题（*iOS Light*、*Dark Studio*、*Classic*）以及 **智能自动更新**。
