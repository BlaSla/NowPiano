# NowPiano

**PDF/MIDI sheet music player with real piano sound.**

Приложение для распознавания и воспроизведения нот из PDF и MIDI-файлов.

## Возможности

- Распознавание нот из PDF — через Audiveris (OMR)
- Воспроизведение MIDI — с падающими нотами (piano roll)
- Реалистичный звук пианино — FluidSynth + SoundFont Arachno
- Красивый Qt-интерфейс — светлая тема, крупные иконки
- Управление — Play, Pause, Stop, Rewind, Loop
- BPM-регулятор — от 30 до 200
- Экспорт в MIDI

## Требования

- Windows 10/11 (x64)
- Java 17 — https://adoptium.net/temurin/releases/?version=17
- Python 3.11+ — https://www.python.org/downloads/
- Audiveris — https://github.com/Audiveris/audiveris/releases
- FluidSynth — C:\tools\fluidsynth\
- SoundFont Arachno — C:\tools\fluidsynth\soundfonts\
