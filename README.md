# NowPianoV2

**Музыкальный плеер, MIDI-плеер и редактор нот для Windows.**

NowPianoV2 распознает ноты из PDF и изображений, воспроизводит MIDI, работает с плагинами и подключается к внешним MIDI-контроллерам, позволяя записывать исполнение и визуализировать ноты.

## Возможности

- Распознавание нот из PDF, PNG и JPG с помощью Audiveris и HOMR.
- Воспроизведение MIDI через FluidSynth.
- Поддержка Arachno SoundFont и FluidR3 GM.
- Управление тональностью, темпом и изменением BPM.
- Поддержка клавиатуры на 88, 76 и 61 клавишу.
- Подключение внешних MIDI-устройств через Mido и RtMidi.
- Запись исполнения с внешних MIDI-контроллеров.
- Визуализация проигрываемых нот на экране пианино и в редакторе нот.
- Встроенные эффекты: реверберация, хорус, эквалайзер, панорама.
- Экспорт записанного исполнения в MIDI.
- Экспорт готовых партитур в PDF через MuseScore Studio 4.

## Инструкция

1. Откройте раздел Releases на GitHub.
2. Скачайте NowPianoV2_Full_Setup_20261103.exe для версии v2.1.
3. Запустите установщик на вашем компьютере.
4. Следуйте указаниям на экране для установки программы.

Данное приложение включает в себя встроенные компоненты сторонних разработчиков, в том числе MuseScore Studio 4.7.5, Audiveris, HOMR, Poppler, FluidSynth и SoundFonts. Компоненты MuseScore используются для генерации партитур в PDF по умолчанию.

Внешний MIDI-синтезатор настраивается отдельно.

## Сборка из исходников

Для сборки необходим Windows x64, Python, PyInstaller и Inno Setup 6.

Файлы конфигурации сборки проекта:

- installer/NowPianoV2_Full_20261103.spec
- installer/NowPianoV2_Full_20261103.iss

Сборщик включает полную установку внешних зависимостей: SoundFonts, HOMR, Audiveris, Poppler и предустановку MuseScore Studio 4.7.5 для корректной работы программы. Для сборки выполните в терминале запуск PyInstaller на файле spec и запустите Git-скрипт. Готовый инсталлятор появится в директории сборщика после завершения работы утилиты.
