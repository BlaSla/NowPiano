# NowPianoV2

**Распознавание нот, MIDI-плеер и цифровое пианино для Windows.**

NowPianoV2 распознаёт ноты из PDF и изображений, воспроизводит MIDI, работает с виртуальной и внешней MIDI-клавиатурой, позволяет записывать исполнение и экспортировать результат.

## Возможности

- Распознавание нот из PDF, PNG и JPG с помощью Audiveris и HOMR.
- Воспроизведение MIDI через FluidSynth.
- Встроенные Arachno SoundFont и FluidR3 GM.
- Управление воспроизведением, перемотка и регулировка BPM.
- Виртуальные клавиатуры на 88, 76 и 61 клавишу.
- Подключение внешней MIDI-клавиатуры через Mido и RtMidi.
- Запись исполнения с внешней MIDI-клавиатуры.
- Отображение записываемых нот на нотном стане в реальном времени.
- Управление записью: Старт, Пауза, Продолжить, Стоп.
- Экспорт записанного исполнения в MIDI.
- Экспорт нотной партитуры в PDF через MuseScore 4.

## Установка

1. Откройте раздел Releases на GitHub.
2. Скачайте NowPianoV2_Setup_Final.exe из релиза v2.1.
3. Запустите установщик.
4. Запустите программу из меню Пуск или с рабочего стола.

Установщик включает FluidSynth, SoundFont, Audiveris, HOMR и Poppler.

**Важно:** для экспорта партитуры в PDF требуется отдельно установленный MuseScore 4. Внешняя MIDI-клавиатура необязательна.

## Сборка из исходников

Требуется Windows 10/11 x64, Python 3.11 x64, PyInstaller и Inno Setup 6.

Для полной All-in-One сборки дополнительно нужны ресурсы SoundFont, FluidSynth, Audiveris, HOMR и Poppler. Из-за большого размера они не входят в обычный Git-клон.

Python-зависимости: PyQt6, pyfluidsynth, pdf2image, Pillow, music21, numpy, mido, python-rtmidi, requests.

Сценарий сборки: installer/NowPianoV2_Release.spec.
